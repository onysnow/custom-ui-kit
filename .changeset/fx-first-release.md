First release of the effects system extracted from the OnySnow Studios site: the shared WebGL engine, optics, light, camera, materials, scene graph, water, balloons, fireworks, webs and secrets modules, 40 React components, the tuning registry, and the `fx-components` stylesheet. The app-specific admin gate and asset settings are replaced by `configureFx`. Binary assets ship separately in `@onysnow/fx-assets`.
